# 合成データ（感情文・中立文）

ステアリングベクトルの抽出と感情プローブの学習に使ったデータ。
公開リポジトリには形式を示すサンプル（`sample_*.jsonl`）のみを含める。

| ファイル | 件数 | 用途 |
|---|---|---|
| `emotions_spoken_739.jsonl` | 739件 × 8感情 = 5,912件 | ステアリングベクトルの抽出、感情プローブの学習 |
| `neutral_spoken_739.jsonl` | 739件 | 中立部分空間 U の推定、平均ノルム n̄ の計算、プローブの neutral クラス |

- 生成モデル: gemma-4-12b-it（Apache 2.0）
- 感情はプルチックの8基本感情、強度は5段階（`level` 1〜5、中立は 0）
- 生成時の制約: 感情語そのものの使用を禁止 / 場面設定を指定して多様性を確保 / 話し言葉のみ使用
- 生成後のフィルタ: 日本語文字の比率、文の長さ、感情語の混入、近似重複

1行の形式:
```json
{"emotion": "neutral", "level": 0, "topic": "窓の外を見る", "style": "spoken", "text": "窓の外に、白い車が横切ったのが見えたよ。", "generator": "gemma-4-12b-it"}
```

全データで作り直す場合は、この2ファイルをここに置いて `python scripts/build_assets.py` を実行する。
